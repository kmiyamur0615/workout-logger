# Appleヘルスケア連携 iOSショートカット設定ガイド

Workout Loggerでは、Appleヘルスケアと連携するために2つの便利なショートカットを利用できます。

---

## 1. ヘルスケアから最新体重を取得するショートカット (`GetWeightFromHealth`)

Workout Loggerの「設定」画面にある「Appleヘルスケアから最新体重を取得」ボタンを押した際に、ヘルスケア内の最新体重を読み取ってアプリに自動入力するレシピです。

### 作成手順（所要時間: 1分）
1. iPhoneで **「ショートカット」アプリ** を開き、右上の **「＋」** をタップ。
2. 上部のショートカット名をタップして「**GetWeightFromHealth**」に変更。
3. **「アクションを追加」** をタップし、「**ヘルスケア**」で検索。
   - アクション「**ヘルスケアのサンプルを検索**」を追加。
   - **タイプ**: `体重`
   - **並び順**: `開始日`
   - **順序**: `最新日順`
   - **制限**: `オン`（1個のサンプルを取得）
4. **「アクションを追加」** をタップし、「**URL**」で検索。
   - アクション「**URL**」を追加。
   - 内容を以下のように入力:
     `ショートカットの入力?weight=ヘルスケアのサンプル`
     （※「ショートカットの入力」と「ヘルスケアのサンプル」は青い変数バブルを選択）
5. **「アクションを追加」** をタップし、「**Safari**」で検索。
   - アクション「**URLを開く**」を追加。
6. 右上の **「完了」** をタップ。

> これで設定画面からボタンを押すだけで、ヘルスケアの最新体重がWorkout Loggerに自動反映されます！

---

## 2. ワークアウトをヘルスケアに書き込むショートカット (`WorkoutLoggerSync`)

ワークアウト終了時に、ヘルスケアへ筋力トレーニング記録を追加するレシピです。

### 作成手順
1. 「ショートカット」アプリで新規作成。
2. 名前を「**WorkoutLoggerSync**」に変更。
3. アクション「**テキストから辞書を取得**」を追加（入力元: `ショートカットの入力`）。
4. アクション「**ヘルスケアのサンプルを記録**」を追加:
   - **カテゴリー**: `ワークアウト`
   - **アクティビティタイプ**: `機能的筋力トレーニング` (または `トラディショナル筋力トレーニング`)
   - **開始日**: 辞書の値（キー: `startDate`）
   - **終了日**: 辞書の値（キー: `endDate`）
5. 右上の **「完了」** をタップ。
