# Workout Logger - Google スプレッドシート ＆ GAS セットアップ手順

Workout Loggerのバックエンド（データベース）としてGoogleスプレッドシートを利用するための手順です。  
所要時間は約3分で、サーバー費用は完全無料です。

---

## 手順 1: Google スプレッドシートの新規作成
1. Googleドライブまたはブラウザで [Google スプレッドシート](https://sheets.new) を開き、新しいスプレッドシートを作成します。
2. シート名を「**Workout Logger DB**」などに変更します。

---

## 手順 2: Google Apps Script (GAS) の設定
1. スプレッドシート上部のメニューから **「拡張機能」>「Apps Script」** をクリックします。
2. エディタが開いたら、最初に入力されているコードをすべて削除し、このフォルダ内の [`Code.js`](./Code.js) の内容をすべて貼り付けます。
3. エディタ上部の **保存アイコン（💾）** をクリックして保存します。

---

## 手順 3: シートの自動初期化
1. ツールバーの関数選択プルダウン（初期値は「myFunction」等）から **`setupSpreadsheet`** を選択します。
2. **「実行」** ボタンをクリックします。
3. 初回実行時、「承認が必要です」というダイアログが表示されるので：
   - 「権限を確認」をクリック
   - ご自身のGoogleアカウントを選択
   - 「詳細」リンクをクリック
   - 「Workout Logger (安全ではないページ) に移動」をクリック
   - 「許可」をクリック
4. 実行が完了すると、スプレッドシートに以下のシートタブが自動生成され、ヘッダーとサンプルデータが設定されます：
   - `schedule` (曜日設定)
   - `menus` (メニューマスタ)
   - `menu_exercises` (メニュー構成種目)
   - `exercises` (種目マスタ)
   - `workouts` (セッション履歴)
   - `sets` (セット詳細履歴)

---

## 手順 4: ウェブアプリとしてデプロイ
1. 右上の青い **「デプロイ」>「新しいデプロイ」** をクリックします。
2. 左側の歯車アイコンをクリックし、**「ウェブアプリ」** を選択します。
3. 以下の通り設定します：
   - **説明**: `v1` (任意)
   - **次のユーザーとして実行**: `自分` (デフォルト)
   - **アクセスできるユーザー**: **`全員`** (重要: iPhoneからアクセスするため)
4. **「デプロイ」** をクリックします。
5. 表示された **「ウェブアプリの URL」**（`https://script.google.com/macros/s/.../exec`）をコピーします。

---

## 手順 5: Workout Logger アプリへの設定
1. iPhoneでWorkout Loggerを開きます。
2. 下部ナビゲーションの **「設定」**（または右上の設定アイコン）を開きます。
3. 「GAS Web App URL」の入力欄に、手順4でコピーしたURLを貼り付けます。
4. **「設定を保存する」** をタップします。
5. **「スプレッドシートから最新取得」** をタップして、「同期が完了しました」と表示されれば連携成功です！
